📋 Google Apps Script (GAS) 快速安裝教學：

  1. 開啟您的 Google Sheets 試算表，點選上方選單 「擴充功能」 → 「Apps Script」。
  2. 貼上右下方程式碼，點擊儲存（軟碟圖示）。
  3. 點選右上角 「部署」 → 「新增部署」，類型選擇 「Web 應用程式」。
  4. 「誰可以存取」 必須選擇 「所有人 (Anyone)」，然後點擊「部署」。
  5. 複製生成的 Web App 網址貼回上方框中即可完成連結！
